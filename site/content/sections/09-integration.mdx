## Integration

Copy the complete, working project for your setup. Its README, under "How Reylo is wired in", names every line Reylo needs:

| Setup | Example | Database and driver |
| --- | --- | --- |
| Node | [examples/node](https://github.com/colinhacks/reylo/tree/main/examples/node) | Postgres, postgres.js |
| Nub | [examples/nub](https://github.com/colinhacks/reylo/tree/main/examples/nub) | SQLite, `node:sqlite` |
| Bun | [examples/bun](https://github.com/colinhacks/reylo/tree/main/examples/bun) | SQLite, `bun:sqlite` |
| Vite, in a React Router app | [examples/vite](https://github.com/colinhacks/reylo/tree/main/examples/vite) | Postgres, `pg` |
| Next.js | [examples/nextjs](https://github.com/colinhacks/reylo/tree/main/examples/nextjs) | Postgres, postgres.js |
| esbuild | [examples/esbuild](https://github.com/colinhacks/reylo/tree/main/examples/esbuild) | Postgres, postgres.js |
| webpack | [examples/webpack](https://github.com/colinhacks/reylo/tree/main/examples/webpack) | MySQL, `mysql2` |
| Rspack | [examples/rspack](https://github.com/colinhacks/reylo/tree/main/examples/rspack) | Postgres, `pg` |
| Jest | [examples/jest](https://github.com/colinhacks/reylo/tree/main/examples/jest) | SQLite, `better-sqlite3` |
| Cloudflare Workers | [examples/cloudflare-workers](https://github.com/colinhacks/reylo/tree/main/examples/cloudflare-workers) | SQLite, Cloudflare D1 |
